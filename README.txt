OPTOCOUPLER THERMAL-CYCLING RELIABILITY ANALYSIS
TR-2026-412.R2

DATA AND MODEL

The 48 device records are in data/optocoupler_ttf_unit_level.csv.
Durations are hours. Analysis scripts calculate cycles = ttf_hours / 3;
the rounded helper column is not used for fitting.

The primary model is a Weibull distribution with
  log(eta) = beta0 - beta1 * log(delta_T).
Failures contribute the density and administrative run-outs the survival
probability. Baseline priors are Gamma(9,3) for k, restricted to k > 1;
Normal(2.5,0.8^2) for beta1, restricted to beta1 > 0.5; and Normal(18,4^2)
for beta0. Gamma parameters use shape-rate notation.

RUNNING THE CHECKS

Use Python 3.12 or 3.13. Run these commands from the repository root:

  python -m pip install -r requirements.txt
  python code/verify_results.py
  python code/r2_checks.py
  python code/reproduce_results.py
  python code/supplementary_checks.py

The fast verifier checks the primary fit, omission fits, profile interval,
common-shape diagnostic, retained posterior summaries and PICM-C behaviour.
r2_checks.py adds whole-group and failure-only transition omissions, relaxed-
support summaries and monotonicity-conditioned PICM-C intervals.
reproduce_results.py writes its tables to results/recomputed/.

For independent posterior integration, including LOSO failure counts:

  python code/independent_checks.py --nodes 160
  python code/independent_checks.py --nodes 220 --wide

The second command checks wider integration bounds. Life quantiles are found
by integrating the posterior CDF to the exact threshold; no rounding to
discrete integration nodes is used. Integration summaries are
independent numerical checks. The reported MCMC tables use the retained
draws, whose stochastic sampling paths are not regenerated by these commands.

BASELINE IMPLEMENTATION

code/baseline_analysis.py retains the statistical implementation from
commit 2c649af41936d08464f90f2286b794f9bae3a681, including the original
sampling, Firth-type and Bartlett routines. Automatic package creation
and Markdown-report generation have been removed; its output directory
is results/baseline_recomputed/. It can be run separately with:

  python code/baseline_analysis.py

That longer run retains the baseline script's historical settings. Use the
retained draws and the R2 scripts above to reproduce the final manuscript
summaries, including the equal-length prior-sensitivity comparisons.
The earlier repository's same-seed support check and the R2 retained
relaxed-support run are different calculations; their Monte Carlo shifts
should not be interchanged.

The intercept prior centre of 18 is fixed in the baseline code. No external
life-data calibration for this centre is documented. The reported prior
sensitivity comparisons retain it and assess scales and slope support.

results/provenance.json records hashes of the measured input and retained
draw files. These inputs are preserved unchanged. The archive contains no
raw electrical time-series logs or original X-ray acquisition data; those
are separate experimental records. Figures in the manuscript must not be
used as substitutes for those raw measurements.
